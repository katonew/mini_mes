원자재 투입 등록

진행 중인 작업지시의 확정 BOM에서 원자재를 선택하고 실제 소비수량을 입력합니다.

작업지시·BOM 구성 선택

작업지시를 조회한 뒤 BOM 구성을 선택해 다시 조회합니다. 기준 조회는 LOT 선택·수량 입력을 초기화하고 같은 요청 키를 유지합니다. 새로운 소비는 신규 등록에서 시작해 주세요.

BOM 구성 원자재기준 소요량지시수량 기준 예상량누적 소비 / 반환 / 순소비순소비 − 예상
예상량과 실제 합계는 작업지시·원자재·보존 단위 기준입니다. 동일 원자재가 여러 구성행이면 품목 합계를 반복 표시하므로 행끼리 다시 합산하지 않습니다. 나누어떨어지지 않는 예상량은 정확한 나눗셈 식으로 표시합니다.
처리하지 못했습니다.

실제 소비 입력

선택한 LOT 단위로 입력합니다. 양수·소수 6자리 이내, EA 정수, 최대 999999999999.999999. 예상량 초과만으로 차단하지 않으며 LOT 가용수량은 초과할 수 없습니다. 조회 후 가용수량이 바뀔 수 있습니다.

소비시각과 작성자는 서버에서 기록합니다. 오류·재전송은 같은 요청 키와 같은 입력으로 재시도해 주세요. 이미 성공한 요청이면 당시 결과를 다시 표시합니다.
