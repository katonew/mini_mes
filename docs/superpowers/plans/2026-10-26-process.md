# 공정 관리 구현 계획

**Goal:** 기존 품목 관리와 같은 MVC·MyBatis 구조 및 공통 UI로 공정 목록·등록·상세 겸 수정을 제공한다.

**근거:** mini_mes_prd.md FR-03, database-design.md 4.5/4.8, schema.sql manufacturing_process/routing_step 및 사용자 3차 개발 요청. 별도 수정 승인 없이 진행한다는 기존 지시를 유지한다.

**설계:** 코드 전역 UNIQUE·등록 후 고정, 명칭 필수 200자, 설명 선택 500자, 사용 여부 0/1. 작성자는 신규 INSERT에만 MES_ACTOR_ID 사용. 미사용 전환은 기존 Routing을 갱신/삭제하지 않으며 신규 Routing 선택 제한은 후속 Service 책임이다. process_name_snapshot은 변경하지 않고 description은 현재 기준정보로 표시한다. 공정별 실적·순서·Routing 개정 사용 상태는 범위 밖이다.

**검증 제한:** 사용자 지시에 따라 빌드·테스트·린트·브라우저·렌더링·개발서버·DB 실행 없음. 테스트는 작성만 하며 실제 통과·DB 롤백·이력 보존 실행 검증을 주장하지 않는다. commit/push 요청은 이번 요청에 없으므로 변경은 작업 폴더에 남긴다.

**리뷰 기록:** 독립 읽기 전용 리뷰에서 공정 DB 조회 오류 모델에 activeMenu가 없어 품목 목록으로 안내되는 문제를 확인했다. 예외 처리 시 새 모델을 사용하는 원인에 맞춰 공통 DB 오류 처리에서 공정 요청의 메뉴값을 설정하고 모델 검증 테스트를 보완했다. 실행 검증은 하지 않았다.
