# BOM 관리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 사용자 실행 금지 지시가 테스트 실행·커밋 자동화보다 우선한다.

**Goal:** 품목 화면과 같은 디자인·계층으로 BOM 등록, 버전 추가, 조회, 제한적 수정을 제공한다.

**Architecture:** Controller → Service → MyBatis XML. bom / bom_version / bom_component를 기존 스키마 그대로 사용한다. Service에서 부모 잠금, 품목 검증, 수량 검증 및 원자 저장을 수행한다.

**Tech Stack:** Java 17, Spring MVC, MyBatis, MySQL, Thymeleaf, 기존 JavaScript/CSS, JUnit 5/Mockito/MockMvc.

**Spec:** 사용자 2026-10-26 요청 및 권장안 승인; mini_mes_prd.md FR-02, business-rules.md, database-design.md 7.2, schema.sql.

## Global Constraints
- 스키마·의존성 변경 없음. 빌드·테스트·브라우저·DB 실행 없음. 운영 OCI 데이터 접근 없음.
- FINISHED/EA 활성 품목, base_qty=1, RAW 구성 1개 이상, 구성 중복 금지.
- EA 정수, M/G 소수 6자리 및 DECIMAL(18,6) 범위. 절삭·환산 없음.
- 미사용 버전은 기존 소요량 변경·구성 추가만 허용. 제거·교체는 새 버전. 사용 이력 이후 변경 금지.
- BOM 코드·제품·기존 버전번호 불변. 상태 컬럼 및 수동 상태 전이 없음.
- 별도 승인 재요청 없이 현재 체크아웃에서 구현. 파일·코드 정적 검토만 수행.

## Review Focus
- 동시 품목 비활성화: 저장 전에 관련 품목을 PK 순서로 잠금.
- 오래된 수정 폼/중복 재전송: 잠금 후 서버 원본 fingerprint와 비교, 충돌 거절.
- first_used_at 누락이 있는 작업지시 참조: 참조 존재도 확인해 수정 차단.
- 삭제·행 ID 바꿔치기·버전/품목 변경 요청: 원본 행과 전수 비교.
- DB 조회 장애와 폼 숫자 변환 오류: 입력 유지, 안전한 오류, 성공 안내 금지.

## 실행 기록
- 테스트 실행 금지에 따라 RED/GREEN 실행 검증은 생략한다. 테스트 통과 및 MySQL 동시성 검증을 주장하지 않는다.
- 독립 읽기 전용 리뷰: 확정 구현 결함 발견 없음. 실제 DB 롤백과 HTML 렌더링은 검증 공백으로 보고받았다. 모의 TransactionManager 기반 Spring 프록시 롤백 테스트를 추가했으며 실제 DB 검증은 실행 금지에 따라 남겨 두었다.
- 스키마에 동일 원자재 UK가 없는 점과 향후 작업지시의 잠금 규약 공유는 승인된 범위의 한계로 유지한다. Routing/작업지시 생성 구현으로 범위를 확장하지 않는다.
